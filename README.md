# CIFAR-10 Classification Performance, Interpretability, and Generalization Analysis

This repository contains the complete codebase and implementation details for Assignment 2 in the  Neural Networks course. The project conducts an empirical investigation into how distinct neural network architectures, specifically Multi-Layer Perceptrons (MLPs), Convolutional Neural Networks (CNNs), and custom Hybrid topologies, impact optimization stability, parameter efficiency, interpretability, and generalization.

You can find the codes for all the improved/upgraded/changed models in "Impoved_codes(Answers) folder:
1. *All_codes_answers:* contains notebook with all the codes for new (modified) models
2. *Task#1_CNN_debugging:* contains notebook with the code for the modified model of CNN
3. *Task#2_Comparison_to_MLP:* contains notebook with the codes for MLP implementation and it's comparison to the modified CNN
4. *Task#3_Iverfitting_Analysis:* contains notebook with the codes for overfitted model and two possible ways to solve it
5. *Task#4_Data_Augmentation:* contains notebook with the codes for the model with augmented data set
6. *Task#5_Hybrid_Network:* contains notebook with the codes for the hybrid CNN+MLP model

You can find the *original model code* in the Instructions folder in "Project_#2_Original_Code" notebook file.

All the instructions for the projects and the task are present in the Instructions folder.
